# Документация TAIF-mail

Этот каталог — основная точка входа в документацию проекта для разработчиков,
администраторов и пользователей приложения.

## Документация для разработчиков

Начинайте отсюда, если нужно менять код:

- [Обзор для разработчика](developer/README.md): карта репозитория и быстрый
  вход в проект.
- [Архитектура](developer/architecture.md): компоненты приложения и общий поток
  данных.
- [Конфигурация](developer/configuration.md): локальные файлы, переменные
  окружения и учетные данные.
- [Обработка почты](developer/email-processing.md): IMAP, состояния письма,
  вложения и управление pipeline.
- [Интеграция с Directum](developer/directum-integration.md): OData-запросы,
  правила, пересылка писем и задачи на проверку.
- [AI и OCR](developer/ai-and-ocr.md): распознавание PDF, Ollama, промпты и
  проверка результата.
- [Фронтенд и Socket.IO-события](developer/frontend-and-events.md): маршрут
  Flask, события интерфейса и состояние страницы.
- [Тестирование и сопровождение](developer/testing-and-maintenance.md): тесты,
  команды проверки и типовые сценарии изменений.
